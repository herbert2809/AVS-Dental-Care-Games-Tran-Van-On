# Dental Care Games – TiH Tran Van On (Unit 5)

Classroom games for the AVS Open House lesson "Unit 5: Dental Care" (Amazing Science 1, Grade 1) at TiH Tran Van On.
The games are made for one shared screen and five groups (Red, Blue, Green, Yellow, White). The games show no team names; the teacher keeps points on the board.
This version uses the four phrases of the Tran Van On lesson: brush your teeth, eat candy, go to the dentist, chew on pencils. Sentences stay simple ("I go to the dentist."), with no time phrases.

## Games

| File | Game | Lesson stage |
| --- | --- | --- |
| `index.html` | Home page with all games | |
| `game1-good-or-bad.html` | Good or Bad for Your Teeth? Six numbered tiles: the teacher models one, then one for each team | Lead-in |
| `game2-listen-and-tap.html` | Listen and Tap. Six questions with recorded audio (works offline): one teacher model, then one for each team | Presentation |
| `game3-happy-or-sad-tooth.html` | Happy Tooth or Sad Tooth? Ten cards to sort (two for each team) | Practice |
| `game4-pop-and-say.html` | Pop and Say. A teacher model round (eat candy), then each phrase twice under bubbles | Practice |
| `game5-lucky-tooth.html` | Lucky Tooth. Tooth T for the teacher, then one for each team; simple "I …" sentences | Production |
| `timer.html` | Countdown timer, 3 minutes. `timer.html?m=4` starts at 4 minutes | Production |

## How to use

- Online: open the GitHub Pages link of this repository.
- Offline: download the HTML files and open `index.html` in Chrome or Edge. Each file works without internet.
- Game 2 plays a recorded voice for each phrase. Tap "Listen" or the ear to hear it again. Turn the speakers on.

## Editing

The files in the main folder are built from `src/`. After changing anything in `src/`, run `python3 build.py`.
All pictures are original drawings made for these games. The Game 2 voice was made with the open Kokoro text-to-speech model.
